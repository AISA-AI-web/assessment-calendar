# AISA Assessment Calendar

A school-wide assessment calendar, so that teachers can see what students
already have on a given day before scheduling a new assessment. It runs as a
Google Apps Script web app backed by a Google Sheet, and it brings in the
school's Internal Calendar and the grade-level assessment calendars.

Phase 1 covers Grades 6–12; K–5 follows as a separate deployment of the same code.

Decisions, defaults and open questions: [docs/DECISIONS.md](docs/DECISIONS.md).
